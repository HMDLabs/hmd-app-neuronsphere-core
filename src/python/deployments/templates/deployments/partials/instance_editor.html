{% comment %} Instance editor. Rendered by changeset_edit_item_instance into the per-item form in changeset_items.html, whose
  • x-data supplies `v` (the selected version, seeded from the item's current version) and `vq`. The version control mirrors the "Add Instance" picker in changeset_draft.html: a hidden input carries the value, a search box loads one page of versions at a time, and results land in a scoped container. Element ids are suffixed with the item index so several open panels do not fight over the same ids. The hidden input starts pre-seeded with the item's current version -- both as a `value` attribute and via `v` -- so saving without touching the list is a no-op for the version, and the current version never has to appear in the fetched page. The repo class is fixed here (it cannot be changed from this panel), so it rides in the hx-get query string; htmx appends the search box's own `version_q` value to it. That keeps the picker self-contained: no hx-include of [name=...] selectors, which would reach into every other open panel and the Add form. {% endcomment %}
